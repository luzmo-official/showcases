# Invite a teammate

Use this workflow when a workspace admin wants to add another person.

1. Open **Workspace settings**.
2. Select **Members**.
3. Choose **Invite teammate**.
4. Enter their work email and role (`Admin`, `Editor`, or `Viewer`).
5. Send the invitation. They receive an email with a 7-day accept link.

Only admins can invite teammates. If the person already belongs to another workspace, they can accept and switch workspaces from the account menu.

Need to remove access later? Open **Members**, find the user, and choose **Revoke**.
